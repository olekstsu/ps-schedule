# Класи



## `class Schedule(domain: str, params: ScheduleParameters)`
Основний клас для отримання розкладу.

**Поля:**
* [`domain: str`](#domain-str) — Домен ПС-Деканат (наприклад "https://dekanat.nung.edu.ua/", посилання може відрізнятись для вашого навчального закладу).
* [`params: ScheduleParameters`](#params-scheduleparameters) — Параметри запиту до розкладу.

**Методи:**
* [`def get(self) -> list[ScheduleTable]`](#def-getself---listscheduletable) — Повертає список таблиць розкладу

### `domain: str`
Домен краще витягувати напряму з сайту розкладу а не з домашньої сторінки "ПС-Деканат", бо є ВНЗ які мають різні домени на домашню сторіну і розклад.

### `params: ScheduleParameters`
Параметри запиту які при створенні об'єкта класу передаються на сервер "ПС-Розклад" для отримання розкладу.

### `def get(self) -> list[ScheduleTable]`
Обов'язково треба викликати цю функцію щоб отримати список таблиць розкладу (`ScheduleTable`).

Для зручності можете викликати її одразу після опису класу:
```python
s = Schedule("...", ScheduleParameters(...)).get()
```


## `class Search(self, domain: str, params: SearchParameters)`
Клас для пошуку викладачів або груп.

**Поля:**
* [`domain: str`](#domain-str-1) — Домен ПС-Деканат (наприклад "https://dekanat.nung.edu.ua/", посилання може відрізнятись для вашого навчального закладу).
* [`params: SearchParameters`](#params-searchparameters) — Параметри для пошуку.

**Методи:**
* [`def get(self) -> list[str]`](#def-getself---liststr) — Повертає результат пошуку у вигляді списку рядків.

### `domain: str`
Домен краще витягувати напряму з сайту розкладу а не з домашньої сторінки "ПС-Деканат", бо є ВНЗ які мають різні домени на домашню сторіну і розклад.

### `params: SearchParameters`
Параметри для пошуку, які аналогічно класу `Schedule`, передаються на сервер "ПС-Розклад" при створенні об'єкта класу.

### `def get(self) -> list[str]`
Функція для отримання результату пошуку. Повертає список всього що підпадає під задані параметри (`SearchParameters`).



## `class ScheduleParameters(faculty: int = 0, teacher: str = None, course: int = 0, group: str = None, sdate: date = None, edate: date = None)`

Параметри для класу `Schedule`. Заповнюйте ці параметри так само як би ви заповнювали форму у ПС-Розклад.

Кожен з параметрів має аналог у вигляді полів на сайті:

<img width="1161" height="415" alt="image" src="https://github.com/user-attachments/assets/66e3eeb4-2b0a-4cd4-8b93-d5c963cb6611" />

**Приклад використання кожного параметра:**

**❗Не потрібно задавати кожен параметр, задавайте тільки потрібні для отримання розкладу.❗**
```python
s = Schedule("https://dekanat.nung.edu.ua/", ScheduleParameters(
        faculty=1015, # Факультет інформаційних технологій
        teacher="Іванов Іван Іванович", # Викладач
        course=3, # Курс
        group="ІП-24-1К", # Група
        sdate=date(2026, 2, 1), # Від 01.02.2026
        edate=date(2026, 2, 28) # До 28.02.2026
    )
).get()
```

**Поля:**
* [`faculty: int = 0`](#faculty-int--0) — Ідентифікатор факультету (у ПС-Розклад, ідентифікатор можна дізнатись через код елемента випадаючого списку для вибору факультету). Можна отримати за допомогою функції ["get_faculty_id()"]().
* [`teacher: str = None`](#teacher-str--none) — ПІБ викладача. (Пишеться прямо рядком як у ПС-Розклад, коли обираєте викладача).
* [`course: int = 0`](#course-int--0) — Номер курсу. (Необов'язковий параметр, якщо вказано групу).
* [`group: str = None`](#group-str--none) — Назва групи. (Шифр групи відповідно до вашого навчального закладу)
* [`sdate: date = None`](#sdate-date--none-edate-date--none) — Дата початку розкладу. (Необов'язковий параметр, розклад за замовчуванням за поточний тиждень).
* [`edate: date = None`](#sdate-date--none-edate-date--none) — Дата кінця розкладу. (Необов'язковий параметр, розклад за замовчуванням за поточний тиждень).

**Методи:**
* `def get_dict(self) -> dict` — Повертає словник полів класу

### `faculty: int = 0`
*Взагалі використання цього поля у своєму додатку вам нічого не дасть, так як воно використовується для автокомпліта на сайті розкладу (Щоб видавати вам групи і викладачів які відносяться до конкретного факультету). Цей параметр тут тільки через те, що ПС-Розклад його приймає*

1. Код елемента випадаючого списку для вибору факультету, де в атрибуті `value` написаний ідентифікатор.
2. Функція `get_faculty_id()` у цій бібліотеці.

### `teacher: str = None`

**Використання:**

```python
s = Schedule("https://dekanat.nung.edu.ua/", ScheduleParameters(

```

### `date: date`
Дата яка в оригіналі знаходиться над таблицею зі списком пар. Перетворена на тип date для зручності використання.

### `lessons: list[Lesson]`
Список пар (`Lesson`) з цієї таблиці.



## `class Lesson(number: int, start_time: time, end_time: time, description: list[str], links: list[str])`
Представляє собою рядок з таблиці розкладу (`ScheduleTable`).

**Поля:**
* [`number: int`](#number-int) — Порядковий номер пари у таблиці
* [`start_time: time`](#start_time-time-end_time-time) — Час початку пари
* [`end_time: time`](#start_time-time-end_time-time) — Час закінчення пари
* [`description: list[str]`](#description-liststr) — Опис пари. Рядки у списку розбиті згідно з тим як ПС-Розклад переносить їх у рядку таблиці
* [`links: list[str]`](#links-liststr) — Список клікабельних посилань, прикріплених до розкладу

**Методи:**
* `def get_dict(self) -> dict` — Повертає словник полів класу

### `number: int`
Номер пари

### `start_time: time` `end_time: time`
Час початку та кінця пари. Перетворені у тип time для зручності.
Якщо вам потрібен об'єкт `datetime` на основі дати таблиці і часу початку/кінця пари, то це можна зробити методом `datetime.combine()`:
```python
table = s[0] # Отримуємо першу таблицю
d = table.date # Отримуємо дату таблиці
t = table.lessons[0].time # Отримуємо час першої пари в таблиці
dt = datetime.combine(d, t) # Комбінуємо дату та час в datetime об'єкт
```

### `description: list[str]`
Опис пари, в якому зазвичай написано: назву дисципліни, тип пари (лекція, лабораторна, практична...), список груп або просто група та викладач.
Формат запису пар у кожного ВНЗ відрізняється, тому зробити поля name, type, groups та teacher для всіх ВНЗ неможливо.
Однак, цей параметр містить список рядків з яких ви можете легко дістати інформацію і відформатувати під свій ВНЗ.

**Приклад отримання назви пари:**
```python
s = Schedule(domain="https://dekanat.nung.edu.ua/", params=ScheduleParameters(group="ІП-24-1К"))

for day in s.get():
    print(f"===| {day.date} |===")
    for lesson in day.lessons:
        # У розкладі ІФНТУНГ назва пари зазвичай у першому рядку
        # Якщо пари немає, повертаємо порожній рядок
        text = (
            lesson.description[0]
            if len(lesson.description) > 0
            else ""
        )
        print(f"[{lesson.number}]: {text}")
```

### `links: list[str]`
Список посилань, які прикріплені до запису пари у розкладі.

Зазвичай посилання закріпляються як тег `<a href="https://...">`. Цей список містить у собі посилання з таких тегів.

Якщо посилання прикріплено як простий текст (не виділяється синім на сторінці), воно не буде у цьому списку і його прийдеться діставати з `description`.



## `class SearchParameters(type: SearchType, query: str, faculty: int = 0, course: int = 0)`
Параметри для класу `Search`.

**Приклад використання:**
```python
s = Search(
    domain="https://dekanat.nung.edu.ua/",
    params=SearchParameters(type=SearchType.GROUP, query="ІП")
).get()
```

Цей код поверне наступний список рядків:
```python
['ІП-22-1', 'ІП-22-2', 'ІП-22-3', 'ІП-22-4', 'ІП-23-1', 'ІП-23-2', 'ІП-23-3', 'ІП-23-4', 'ІП-24-1', 'ІП-24-1К', 'ІП-24-2', 'ІП-24-3', 'ІП-25-1', 'ІП-25-2', 'ІП-25-3', 'ІП-25-4К', 'ІПз-22-1', 'ІПз-23-1', 'ІПз-24-1', 'ІПз-25-1', 'ІПм-24-1', 'ІПм-24-2', 'ІПм-24-3', 'ІПм-25-1', 'ІПм-25-2', 'ІПмз-24-1', 'ІПмз-25-1']
```

Взагалі, можливо отримати повний список викладачів та груп з усіх факультетів. Для цього достатньо всього лиш передати у `query` порожній рядок:
```python
s = Search(
    domain="https://dekanat.nung.edu.ua/",
    params=SearchParameters(type=SearchType.TEACHER, query="")
).get()
```

**Поля:**
* [`type: SearchType`]() — Тип для пошуку.
* [`query: str`]() — Запит за яким робити пошук.
* [`faculty: int`]() — Ідентифікатор факультету. Можна отримати через функцію `get_faculty_id()`.
* [`course: int`]() — Номер курсу. Необов'язковий параметр, якщо тип пошуку `SearchType.TEACHER`.

**Методи:**
* `def get_dict(self) -> dict` — Повертає словник полів класу

### `type: SearchType`
Тип для пошуку (Викладач чи Група). Пошук поверне ПІБ викладачів або шифри груп.

```python
teachers = ["Іванов Петро Васильович", "Петров Василь Іванович", "Васильков Іван Петрович", ...]
groups = ["ІП-24-1", "ІП-24-1К", "ІП-24-2", "ІП-24-3", ...]
```

### `query: str`
Запит для пошуку. Може містити тільки частину, щоб отримати декілька результатів.

```python
SearchParameters(SearchType.TEACHER, "Іван") # Поверне викладачів у ПІБ яких міститься частина "Іван"
SearchParameters(SearchType.GROUP, "ІП-24") # Поверне список груп ІП-24-...
```

### `faculty: int`
Параметр для відображення викладачів та груп які відносяться до конкретного факультету.

Є два методи отримання ідентифікатора факультету, які були описані у розділі про `ScheduleParameters`:
1. Код елемента випадаючого списку для вибору факультету, де в атрибуті `value` написаний ідентифікатор.
2. Функція `get_faculty_id()` у цій бібліотеці.

Хоча й можливо отримати повний список викладачів та груп всього навчального закладу, з факультетами не все так добре як хотілось.

Якщо спробувати вивести повний список викладачів факультету, то все буде добре, ви отримаєте правильний список викладачів:
```python
SearchParameters(type=SearchType.TEACHER, query="", faculty=1015)
```

Однак якщо спробувати провернути те саме з групами, ви отримаєте повний список груп всіх факультетів, а не конкретного. Хоча цей параметр працює якщо задати хоча б одну букву у `query`, але це не повний список груп, а конкретно групи які мають у своєму шифрі цю букву:
```python
SearchParameters(type=SearchType.TEACHER, query="І", faculty=1015)
```

Це баг самого API ПС-Розклад. Для того щоб таке взагалі реалізувати прийдеться проганяти кожну букву. Але це вже спам запитами на сервер, який може вам закрити доступ і ваш скрипт повалиться.

### `course: int`
Параметр для відображення груп які вчаться на конкретному курсі.
Параметр не впливає на викладачів.

**Приклад:**
```python
SearchParameters(type=SearchType.TEACHER, query="ІП", course=3) # Виведе список груп ІП-23-... і ІП-24-1К
```

Аналогічно параметру `faculty`, отримати список всіх груп на `n` курсі не вийде через баг API ПС-Розклад.

## `def get_faculty_id(domain: str, faculty_name: str) -> int | None`
Функція для отримання ідентифікатора факультету за його назвою. Ідентифікатор потрібен для заповнення параметрів розкладу та пошуку.

**Аргументи:**
* `domain: str` — Домен ПС-Деканат (наприклад "https://dekanat.nung.edu.ua/", посилання може відрізнятись для вашого навчального закладу).
* `faculty_name: str` — Назва факультету, для якого потрібно отримати ідентифікатор.
    
**Повертає:**
* `int` — Ідентифікатор факультету
* `None` — Якщо факультет не знайдено



## `def get_faculties(domain: str) -> dict[int, str]`
Функція для отримання словника факультетів у ПС-Деканат.

**Аргументи:**
* `domain: str` — Домен ПС-Деканат (наприклад "https://dekanat.nung.edu.ua/", посилання може відрізнятись для вашого навчального закладу).

**Повертає:**
* `dict[int, str]` — Словник факультетів у ПС-Деканат. Ключами є ідентифікатори факультетів, а значеннями — їх назви.
